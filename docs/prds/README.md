# HackHome PRD Pack

This folder splits the HackHome product into focused PRDs that can be owned independently during the hackathon.

## PRDs

1. [Product Vision and MVP](./01-product-vision-and-mvp.md)
2. [Agentic Workflow and Lifecycle](./02-agentic-workflow-and-lifecycle.md)
3. [PostHog Dashboard Builder](./03-posthog-dashboard-builder.md)
4. [Email-Native Buyer Loop](./04-email-native-buyer-loop.md)
5. [Operator Console](./05-operator-console.md)
6. [Demo, Validation, and Judging Plan](./06-demo-validation-and-judging-plan.md)

## How to Use This Pack

- Start with the product vision PRD to understand the complete user promise.
- Use the workflow PRD to implement the backbone first.
- Use the PostHog PRD to build the first live integration.
- Use the email PRD to make the buyer interaction feel natural.
- Use the operator console PRD only after the workflow has real state to display.
- Use the demo PRD to decide what must be finished before judging.

The original consolidated PRD remains at [`../PRD.md`](../PRD.md).
